# 🔧 Aprovisionamiento Headless

> **Navegación**: [← installation](01.2-installation.md) | [network →](01.4-network.md)

Configuración automatizada del sistema operativo mediante los archivos de arranque de DietPi, permitiendo un despliegue completamente *headless* (sin monitor, teclado ni ratón).

---

## 1. 📂 Archivos de Configuración

Tras flashear la imagen, la partición `boot` de la microSD contiene dos archivos clave que se leen en el primer arranque:

| Archivo | Propósito |
|---|---|
| `dietpi.txt` | Configuración general del sistema (red, SSH, software). |
| `dietpi-wifi.txt` | Credenciales de red Wi-Fi. |

### 1.1 Cómo acceder a la partición `boot`

El nombre del volumen y la ruta de montaje **varían según el sistema operativo anfitrión** y no siempre son predecibles (a veces la SD no se monta automáticamente, otras veces el volumen aparece con un nombre distinto). Por eso, en lugar de depender de una ruta fija, se recomienda localizarla usando el explorador de archivos del sistema:

| SO anfitrión | Cómo localizar la partición `boot` |
|---|---|
| **macOS** | Abrir el **Finder** y buscar el volumen de la SD en la barra lateral (puede llamarse `boot`, `BOOT`, `DietPi` o similar). |
| **Linux** | Abrir el **gestor de archivos** y localizar la partición montada. Si no se monta automáticamente, hacerlo desde el propio gestor. |
| **Windows** | Abrir el **Explorador de archivos** y localizar la unidad asignada a la partición `boot` (puede ser `D:\`, `E:\`, etc., según qué otras unidades estén conectadas). |

Una vez dentro de la partición, editar los archivos con cualquier editor de texto plano (TextEdit, VS Code, nano, Notepad++) y guardar los cambios directamente en la SD.

> ⚠️ **Nota:** No asumas que la partición se montará siempre en la misma ruta ni con el mismo nombre. Si no aparece en el explorador de archivos, expulsa la SD de forma segura y vuelve a insertarla, o verifica que el flasheo se completó correctamente.

## 2. 🌐 Configuración de Red Wi-Fi

**Archivo**: `dietpi-wifi.txt`

| Parámetro | Valor ejemplo | Descripción |
|---|---|---|
| `aWIFI_SSID[0]` | `'NombreDeTuRed'` | Nombre de la red Wi-Fi. |
| `aWIFI_KEY[0]` | `'ContraseñaDeTuRed'` | Clave Wi-Fi. ⚠️ El parámetro es `KEY`, **NO** `PASSWORD`. |

> 🛑 **Error común documentado**: usar `aWIFI_PASSWORD` en lugar de `aWIFI_KEY`. La imagen no reconocerá la red si el parámetro es incorrecto. Ver [`06-troubleshooting.md`](../06-troubleshooting.md).

### 2.1 Ejemplo completo de `dietpi-wifi.txt`

```ini
# Wi-Fi SSID
aWIFI_SSID[0]='MiRedBiomedica'

# Wi-Fi Key (⚠️ NO usar aWIFI_PASSWORD)
aWIFI_KEY[0]='MiContraseñaSegura123'

```

## 3. ⚙️ Configuración General

**Archivo**: `dietpi.txt`

### 3.1 Red Wi-Fi

| Parámetro | Valor | Descripción |
| --- | --- | --- |
| `AUTO_SETUP_NET_WIFI_ENABLED` | `1` | Activa la configuración automática del Wi-Fi. |
| `AUTO_SETUP_NET_WIFI_COUNTRY_CODE` | `ES` | Código de país (obligatorio para regulación RF). |
| `AUTO_SETUP_NET_ETHERNET_ENABLED` | `0` | Desactiva Ethernet si no se usa. |

### 3.2 Servidor SSH

| Parámetro | Valor | Descripción |
| --- | --- | --- |
| `AUTO_SETUP_SSH_SERVER_INDEX` | `-2` | Instala OpenSSH (recomendado). `-1` = Dropbear. |
| `AUTO_SETUP_SSH_PUBKEY` | `'ssh-rsa AAAA...'` | Clave pública para autenticación sin contraseña. |
| `SOFTWARE_DISABLE_SSH_PASSWORD_LOGINS` | `0` | Permite login por contraseña. `1` = solo claves SSH. |


### 3.3 Credenciales y Automatización

| Parámetro | Valor | Descripción |
| --- | --- | --- |
| `AUTO_SETUP_GLOBAL_PASSWORD` | `'TuPasswordRoot'` | Reemplaza la contraseña por defecto de `root` y `dietpi`. |
| `AUTO_SETUP_AUTOMATED` | `1` | Cambia valor de 0 a 1 para habilitar la configuración automática. |

> 🔒 **Recomendación de seguridad**: cambiar la contraseña global en el primer arranque mediante `AUTO_SETUP_GLOBAL_PASSWORD`. Si no se define aquí, se debe cambiar tras el primer login con `passwd`.

### 3.4 Ejemplo de `dietpi.txt` (bloque relevante)

```ini
# ─── Red Wi-Fi ───
AUTO_SETUP_NET_WIFI_ENABLED=1
AUTO_SETUP_NET_WIFI_COUNTRY_CODE=ES
AUTO_SETUP_NET_ETHERNET_ENABLED=0

# ─── Servidor SSH ───
AUTO_SETUP_SSH_SERVER_INDEX=-2
SOFTWARE_DISABLE_SSH_PASSWORD_LOGINS=1
# AUTO_SETUP_SSH_PUBKEY='ssh-rsa AAAA...'  # Descomentar para usar clave pública

# ─── Credenciales y Automatización ───
AUTO_SETUP_GLOBAL_PASSWORD='CambiarEstaPassword123'
AUTO_SETUP_AUTOMATED=1
```

## 4. 🔑 Credenciales por Defecto

Si no se define `AUTO_SETUP_GLOBAL_PASSWORD`, el sistema arranca con:

| Campo | Valor |
| --- | --- |
| Usuario | `root` |
| Contraseña | `dietpi` |
| Puerto SSH | `22` |

> ⚠️ Estas credenciales son públicas y conocidas. Cámbialas antes de exponer el nodo a cualquier red que no sea de confianza.
